# 🎮 RandomGame

RandomGame é um projeto desenvolvido com o objetivo de facilitar a escolha de jogos para usuários indecisos, oferecendo uma solução simples, rápida e funcional.

A aplicação realiza a seleção aleatória de jogos com base em gêneros, ajudando o usuário a economizar tempo e iniciar sua experiência de forma imediata.

> A dúvida acabou. Nós escolhemos por você.

---

## 📌 Visão geral do projeto

Muitos jogadores enfrentam dificuldades ao escolher o que jogar, seja pela grande quantidade de opções disponíveis ou por limitações de hardware.  
O RandomGame surge como uma alternativa prática, focada na objetividade e na experiência do usuário.

---

## 🚀 Funcionalidades

- Seleção aleatória de jogos
- Interface simples e intuitiva
- pesquisar sobre o jogo depois de escolhido
- Foco em usabilidade e rapidez
